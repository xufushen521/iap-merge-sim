# 餐厅翻新 Merge-2 一页规则

优先级：U1

## 核心循环

点击生成器消耗能量并获得一级物品 → 点击两个同链同等级物品完成二合 → 合成高阶物品 → 交付订单获得金币与星星 → 使用金币和累计星星完成装修。

## 棋盘

- 棋盘为 6×7，共 42 格。
- 点击第一个物品进入选中状态，再点击同链同等级物品完成二合。
- 二合消耗两张原物品，在第二张物品的位置生成下一等级物品。
- 最高等级物品不能继续二合。

## 能量与生成器

- 生成器每日有独立次数。
- 每次生成消耗对应生成器标示的能量。
- 能量不足、生成器次数为 0 或棋盘已满时，不能生成。
- 推进一天会补发每日能量，并重置全部生成器次数。

## 订单

- 同时展示 3 个订单。
- 订单需求必须全部满足才能交付。
- 交付会移除对应棋盘物品，并发放金币和星星。
- 订单完成后立即补充下一张订单。

## 装修

- 每个阶段同时要求累计星星和当前金币。
- 装修消耗金币，不消耗星星。
- 达到要求时自动推进到下一阶段。

## 货币

| 资源 | 来源 | 消耗 |
|---|---|---|
| 能量 | 每日恢复、IAP、宝石兑换 | 使用生成器 |
| 金币 | 订单、IAP | 装修 |
| 宝石 | IAP | 兑换能量 |
| 星星 | 订单 | 只作为累计装修门槛，不消耗 |

## IAP

- 开业迎新包：一次性购买，包含宝石、能量和金币。
- 后厨能量包：只补充能量。
- 装修宝石包：只补充宝石。
- 周末经营组合：同时补充三类资源。
- 当前原型只模拟购买结果，不连接真实支付。
