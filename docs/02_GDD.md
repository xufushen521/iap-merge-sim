# 餐厅翻新 Merge-2 GDD

优先级：U1

## 产品定位

面向休闲玩家的餐厅翻新 Merge-2。短时操作来自生成与二合，中期目标是订单和装修，长期成长由装修阶段与 IAP 资源包承接。

## 核心体验

- 低阶物品通过二合持续成长，玩家能看到棋盘状态变化。
- 订单把不同物品链转成金币和星星。
- 装修目标提供跨多局的明确进度。
- 能量限制单日操作量，IAP 只在资源真正阻塞后出现。

## 难度与节奏

| 杠杆 | 增加后的影响 | 风险 | 控制方式 |
|---|---|---|---|
| 订单等级 | 需要更多生成与合并 | 早期理解成本上升 | 前几单要求 T2–T3 |
| 生成器成本 | 单次操作更贵 | 能量阻塞提前 | 与每日恢复一起调 |
| 订单数量 | 棋盘消耗加快 | 空间压力下降 | 保持高三阶杂交订单 |
| 装修金币 | 软货币目标延长 | 卡关感增加 | 非付费玩家仍应持续推进 |
| 礼包资源量 | 缩短阻塞时间 | 经营循环被跳过 | 即时与延期资源混合 |

## 商业化原则

1. 礼包拥有明确功能，不做纯概率购买。
2. 能量包解决操作中断，组合包解决复合资源阻塞。
3. 首购包用于低门槛体验完整资源包，但只出现一次。
4. 商品价格和资源量必须在可配置表中管理，不写死在界面。
5. 广告不是本项目首版货币入口，避免 IAA 与 IAP 双轨混账。

## 留存与进度假设

- 非付费玩家依靠每日能量可完成少量订单。
- 第 14 日应能完成至少一个装修阶段，避免首周完全看不到成长。
- 付费玩家推进更快，但仍需执行生成、二合和订单，不能直接跳过玩法。

## 当前非目标

- 不复制具体游戏角色、剧情、餐厅布置或订单文案。
- 不模拟广告观看。
- 不宣称合成收入能代表真实产品。
- 不实现真实支付、账号、云存档和服务器时间。
